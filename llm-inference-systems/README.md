# LLM Inference Systems

Практический курс по системам инференса LLM: от matmul и attention до KV-кэша, квантизации, continuous batching, распределённого инференса и unified-memory нод.

## Структура

```text
llm-inference-systems/
  modules/       18 глав курса, Markdown
  illustrations/ SVG-диаграммы глав
  papers/        конспекты и первичные источники
  outlines/      планы модулей
  specs/         спецификации и контракты
  reviews/       аудиты актуальности
```

Сайт курса: https://hermes-agent.ru/courses/llm-inference/

## Как проходить

Идите по модулям от `00-intro.md` до `17-unified-hybrid.md`. В каждом модуле есть формулы, runnable-код или лабораторная и критерии проверки.
