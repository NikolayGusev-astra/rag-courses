# Хаб курсов

Практические курсы с runnable-кодом: каждый пример запускается локально,
качество измеряется метриками, ничего не платится.

## Курсы

- [RAG Engineering](rag-engineering/README.md) — от вопроса «нужен ли вам RAG»
  до production-сервиса с цитатами: гибридный поиск, реранкинг, eval в CI,
  agentic RAG с MCP-сервером. 11 глав, весь код оффлайн на чистом Python.

Сайт курса: https://hermes-agent.ru/courses/

## Подписка на обновления

Курсы пересматриваются регулярно: новые модели, стеки и подходы проверяются
против материала, при изменениях поднимается версия. Как следить:
[SUBSCRIBE.md](SUBSCRIBE.md).
