# Changelog

Формат: семантическое версионирование. Минор — новое содержание курса
(новая глава, обновлённые рекомендации), патч — исправления кода и фактов.

## [1.1.0] - 2026-10-28

### Актуальность и безопасность (аудит курса, 15 находок закрыто)

- Глава 08 переведена на MCP Python SDK v2: `MCPServer` вместо удалённого
  `FastMCP`, `pip install "mcp>=2"`. Прогнано на живом SDK 2.3.0.
- Калькулятор агента: `eval` заменён строгим AST-парсером (обход пустых
  `__builtins__` закрывается, проверено репро).
- Глава 09: личность пользователя больше не пример «из query-параметра» —
  раздел о том, откуда берётся идентичность в бою; new: prompt injection
  через корпус с тестом-ловушкой; кэш ответов ограничен (256 записей);
  `can_read` доведён до default-deny; p95 по методу ближайшего ранга.
- Глава 05: актуальные модели — `bge-reranker-v2-m3`, Cohere Rerank 4,
  Jina v3, Voyage rerank-2.5; оффлайн-реранкер не сортирует по длине на
  нулевом пересечении.
- Глава 06: guard от пустого корпуса и кривых строк GOLD, токенизация с «ё»,
  происхождение порога THRESHOLD, методика роста золотого набора 5 → 30,
  RAGAS как второй слой оценки.
- Глава 04/06: BM25 не выдаёт документы с нулевым скором на мусорном запросе.
- Глава 01: опечатки пользователя и лексический поиск.
- Глава 00: DuckDB VSS и GPU-индексы (Milvus GPU_CAGRA) в ландшафте.
- Код в `code/`: все 10 файлов синтаксически чисты и прогнаны, шапки
  получили notes по зависимостям (08 требует mcp>=2).

## [1.0.0] - 2026-10-27

### Первый публичный релиз

- 11 глав: от «нужен ли вам RAG» до production-сервиса на FastAPI.
- Гибридный поиск BM25 + dense + RRF, реранкинг cross-encoder.
- Свой eval-раннер (recall@k, MRR, nDCG) и гейт в CI.
- Паттерны HyDE / multi-hop / Corrective RAG / GraphRAG с честной оценкой цены.
- Рабочий MCP-сервер базы знаний (FastMCP).
- Весь код запускается оффлайн на чистом stdlib, кроме глав 05 (опциональный
  transformers), 08 (pip install mcp) и 09 (pip install fastapi uvicorn).
